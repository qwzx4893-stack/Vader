# Getting help

| You want to | Go here |
|---|---|
| Ask how something works or whether Vader can do X | [`docs/FAQ.md`](./docs/FAQ.md), then [Discussions](../../discussions) if enabled, otherwise an [issue](../../issues/new/choose) |
| Report a bug | the **Bug report** issue form; include your Vader version, OS, provider and model, and what the Developer Tools console (`Help > Toggle Developer Tools`) shows |
| Ask for a feature | the **Feature request** issue form |
| Report a security problem | **not** an issue: follow [`SECURITY.md`](./SECURITY.md) |
| Contribute | [`CONTRIBUTING.md`](./CONTRIBUTING.md) |

Before opening a bug, please check that the provider key works outside Vader and that the endpoint in Settings is the one your account uses.
Never paste an API key into an issue; if you did, rotate it.
